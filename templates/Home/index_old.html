Features

Everything you need, nothing you don't.

Live Statistics

Real-time placement data, application pipelines, and drive analytics across all dashboards.

Role-based Access

Students, companies, and admins each get purpose-built views with strict access control.

Audit Logs

Every action is logged — approvals, rejections, applications — for full transparency.

Resume Management

Students upload PDF resumes; companies can view them directly from application cards.

CGPA Filtering

Drives are filtered by eligibility CGPA so students only see drives they qualify for.

Instant Notifications

Status updates on shortlisting, placement, and withdrawals appear in the notification log.
